# PiRadar: původní návrh MVP (archiv)

> **Stav: historický koncept z roku 2025. Tento repozitář není funkční aplikace ani aktuální zdroj pravdy pro PiRadar Continuum.**

Původní záměr: web zaměřený na přehled kryptoměn, komunitní obsah a postavu Kryptokámoše. Repozitář obsahuje pouze dokumentaci, nastavení balíčku a licenční soubor; deklarovaná implementace Next.js zde není. Původní text README proto nepředstavoval ověřený návod k běhu.

## Současný stav projektu

- Aktivní veřejná technická část: [piradar-core](https://github.com/Kostazz/piradar-core).
- Soukromý provozní systém Earn Scout existuje odděleně; jeho přístupy a provoz nejsou součástí tohoto archivu.
- Historie tohoto repozitáře se zachovává jako doklad vývoje konceptu; žádný kód ani oprávnění již udělená pod [licencí MIT](LICENSE) se zpětně neruší.

## Značka a nezávislost

MIT se vztahuje na zde zpřístupněné dílo, nikoli automaticky na práva ke značkám a logům třetích stran. PiRadar není oficiální produkt Pi Network. Oprávnění k označení „Pi“ nelze dovozovat z existence tohoto repozitáře.
